# Constitución del Diario de Estudio

1. **Stack**: HTML, CSS y JS puros. Sin frameworks, npm, bundler ni build.
2. **Spec-código**: `AGENTS.md` define las reglas; el código las implementa sin desviarse.
3. **Separación**: la lógica (cálculos, datos) nunca se mezcla con la interfaz (DOM).
4. **Tests**: verificación manual con Chrome DevTools. Sin dependencias de testing.
5. **Datos**: solo localStorage, en el dispositivo del usuario. Nunca se envían a servidores.
6. **Idioma**: textos de interfaz en español; código y comentarios en español.
